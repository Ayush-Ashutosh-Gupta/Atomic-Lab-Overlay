# Atomic Lab Overlay

Atomic Lab Overlay is a Chrome extension that lets you explore interactive 3D atomic models of all 118 elements. It can run in the popup lab or as an overlay on any webpage.

## Features

- All 118 elements
- Multiple visualization modes:
  - Bohr model
  - Spherical model
  - Quantum cloud simulation
- Webpage overlay mode
- Popup lab mode
- Built for interactive learning and quick reference

## How To Use

1. Install the extension (Load unpacked)
2. Open the popup to use the standalone lab
3. Or activate overlay mode on any webpage
4. Select an element and switch visualization modes

## Tech Stack

- Chrome Extension (Manifest V3)
- React + TypeScript
- Content script overlay system

## Purpose

An educational utility for visualizing atomic structure directly while browsing or studying.
